# 可编辑咨询型 PPT Skill 使用说明

## 这个 Skill 解决什么

它将「澄清需求→调查/内容理解→SVG 确认→原生可编辑 PPTX→完整 QA」固化为标准流程，同时强制保留用户提供的母版、版式、页眉页脚、Logo 和页码。

## 常见调用方式

### 情况一：已有截图或完整内容

> 使用 `$editable-consulting-ppt-workflow`，根据我提供的 PPT 母版和页面截图，先一次只问一个问题澄清页面表达目标，再设计 SVG 预览稿。我确认后，生成完全可编辑的 PPTX。

### 情况二：需要调查和大纲

> 使用 `$editable-consulting-ppt-workflow`，根据项目背景和客户需求开展可靠公开信息调查，区分已验证事实、第三方估算/观点和待验证假设，先给出详细逐页大纲。大纲确认后，分批生成 SVG，确认后输出可编辑 PPTX。

### 批量制作

> 这次每批先给我 3 页 SVG，我批量确认后再生成对应的 3 页 PPTX，最后合并为一份完整演示文稿。

### 明确跳过 SVG 确认

> 这次我明确授权跳过 SVG 审批，请直接生成 PPTX，但仍需完成所有原生可编辑、母版一致性和 QA 检查。

## 强制规则

- 没有用户提供的 PPTX 母版：必须暂停并索取。
- 一次只问一个澄清问题。
- SVG 确认是默认强制关卡，只能由用户明确豁免。
- SVG 只是设计规格，不能整页嵌入并冒充可编辑 PPT。
- 中文用微软雅黑，英文和数字用 Arial。缺失字体时只能交付预览版。
- 二维信息用原生表格；趋势、占比、比较用带内嵌 Excel 的原生图表。
- 照片、产品图、Logo、截图、地图可作为独立图片对象。
- 不能核实的内容要标注为估算、观点或待验证假设。
- 优先以 macOS 版 Microsoft PowerPoint 作为最终验收环境。

## 交付状态

- **Final（最终版）**：所有 QA 及 macOS PowerPoint 验收通过。
- **Candidate（候选版）**：结构和替代渲染已通过，但 macOS PowerPoint 尚未验收。
- **Preview only（仅预览）**：SVG 或使用替代字体/工具生成的文件。
- **Blocked（已阻塞）**：缺失母版、工具能力、证据或必要的 QA 通过条件。
